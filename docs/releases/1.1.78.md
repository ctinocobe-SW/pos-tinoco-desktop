# El Mercader POS 1.1.78

- Ventas detecta por separado una falla del inicio de sesión y una caída de la base de datos. Ante un corte, el administrador puede abrir la pantalla con los datos guardados y seguir cobrando ventas nuevas en efectivo.
- El POS muestra si el equipo está listo para vender sin conexión y avisa cuando el acceso local necesita renovarse o queda poco espacio.
- Cada cobro en efectivo guardado sin red genera una copia cifrada en el equipo. Se puede recuperar y reimprimir desde **Ventas locales**.
- Al reconectar, el POS conserva el importe, la fecha y los identificadores del cobro para sincronizar sin duplicarlo. El motivo de un intento fallido queda visible en el folio.
- El POS conserva las capturas cuando se interrumpe un envío y permite verificar un cierre cuya confirmación se perdió. Los pedidos de otros dispositivos, las transferencias y los créditos requieren conexión para cerrarse.
