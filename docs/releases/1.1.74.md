# El Mercader POS 1.1.74

- El administrador puede tocar el precio de una partida en Editar ticket y usar la calculadora para autorizar otro importe.
- El cambio conserva el folio, se registra con motivo y administrador, actualiza los totales y se mantiene al capturar pesos.
- Disponible también en edición sin modo táctil. Reintentos y cambios concurrentes protegidos.

Disponible para pedidos abiertos sin entrega, pagos ni crédito. Los comprobantes cerrados o facturados conservan sus precios. No cambia precios del catálogo ni existencias. Backend compatible ya publicado. Instalar sobre la versión actual conserva perfil y pendientes; no borrar AppData.
